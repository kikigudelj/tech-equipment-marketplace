# Tech Equipment Marketplace

Full-stack web aplikacija za oglašavanje i pretraživanje računalne opreme. Izrađena u sklopu završnog rada.

## Funkcionalnosti
- Objava oglasa za računalnu opremu
- Pretraživanje oglasa
- [npr. registracija i prijava korisnika, slike uz oglase, kategorije, filtriranje]

## Tehnologije
- Python, Django
- SQLite
- HTML, CSS, JavaScript, Bootstrap

## Pokretanje
1. Kloniraj repozitorij:
   `git clone https://github.com/kikigudelj/tech-equipment-marketplace.git`
2. Uđi u mapu projekta i instaliraj ovisnosti:
   `pip install django` (ili `pip install -r requirements.txt` ako postoji)
3. Pokreni migracije: `python manage.py migrate`
4. Pokreni server: `python manage.py runserver`
